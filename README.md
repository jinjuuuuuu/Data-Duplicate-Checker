# AI 학습/시험 데이터 중복성 검사기

학습데이터와 시험데이터 사이의 **중복(데이터 누출, data leakage)** 을 검사하고 HTML 리포트를 만드는 Windows 프로그램입니다.

AI 시스템 성능시험에서 학습에 쓴 데이터가 시험데이터에 섞여 있으면 시험 결과가 과대평가됩니다. 이 도구는 두 데이터셋을 받아 겹치는 부분을 찾아냅니다.

- 설치·인터넷·계정이 필요 없습니다. 실행파일 하나로 동작합니다.
- 데이터는 실행한 PC를 벗어나지 않습니다.

버전 1.0.2

---

## 검사할 수 있는 형식 — 확장자 25종

| 분류 | 확장자 | 비교 단위 |
|---|---|---|
| 정형 테이블 | `.csv` `.tsv` `.xlsx` `.xlsm` `.xls` `.parquet` | 행 |
| 이미지 | `.jpg` `.jpeg` `.png` `.bmp` `.gif` `.tif` `.tiff` `.webp` `.ppm` | 장 |
| 텍스트 · JSON | `.txt` `.md` `.json` `.jsonl` `.ndjson` `.text` | 문서 |
| NumPy 배열 | `.npy` `.npz` | 샘플 |
| PKL | `.pkl` `.pickle` | 행 또는 샘플 |

확장자를 보고 자동으로 분류합니다. 여러 형식이 섞여 있어도 됩니다.

목록에 없는 형식(영상·음성·압축파일 등)은 내용을 해석하지 않고, **파일 단위 동일성**으로 바이트까지 같은 파일만 걸러집니다.

### 바이트가 달라도 잡는 경우

- **이미지** — 크기를 바꾸거나 다시 저장해 파일 해시가 달라져도 지각 해시(dHash)로 탐지합니다.
- **텍스트** — 인코딩(cp949/UTF-8)·개행(CRLF/LF)·BOM만 다른 문서는 같은 문서로 봅니다.

## 판정 기준

| 항목 | 기본값 | 설명 |
|---|---|---|
| 파일 단위 동일성 | 켬 | SHA-256 이 같은 파일 |
| 완전 일치 | 켬 | 내용이 동일한 단위 |
| 근사 중복 | 켬 | 아래 임계값 안에서 유사한 단위 |
| 수치 허용오차 | 4자리 | 소수점 몇째 자리까지 같으면 같은 값으로 볼지 |
| 텍스트 유사도 | 0.80 | Jaccard 임계값 |
| 이미지 해밍거리 | 5 | dHash 거리. 작을수록 엄격 |

전체 판정은 **완전 일치가 한 건이라도 있으면 FAIL**, 근사 중복만 있으면 WARN, 둘 다 없으면 PASS 입니다.

> 요약 표의 **읽기 실패** 가 0인지 확인하세요. 0이 아니면 그만큼은 열지 못해 검사에서 빠진 것입니다. "중복이 없다"는 뜻이 아닙니다.

## 시작하기

실행파일은 저장소에 없습니다(71MB). 아래 순서로 직접 만듭니다. Windows 와 인터넷 연결이 필요합니다.

**1. 저장소 내려받기**

이 페이지 위쪽 초록색 **Code** 버튼 → **Download ZIP** → 받은 파일 압축 풀기

**2. Python 설치** (이미 있으면 넘어가기)

[python.org](https://www.python.org/downloads/) 에서 받아 설치합니다. 설치 화면 아래 **Add Python to PATH** 를 꼭 체크하세요.

**3. 실행파일 만들기**

압축 푼 폴더에서 `build_exe.bat` 을 더블클릭합니다. 5~10분 걸립니다.

**4. 실행**

만들어진 `dist\데이터중복성검사기.exe` 를 더블클릭합니다.

> 이 EXE 하나만 복사하면 **Python 이 없는 PC 에서도** 돌아갑니다. 업체 PC 에 전달할 때 이 파일을 쓰세요.

**잘 안 되면**

- Python 을 못 찾는다고 나오면 → `diagnose.bat` 더블클릭
- `[WinError 5]` 오류 → `build` 폴더를 지우고 다시 시도 (OneDrive 폴더에서 자주 생깁니다)
- Python 이 이미 있다면 `run.bat` 으로 빌드 없이 바로 띄울 수도 있습니다. 단 이 방식은 parquet·구형 xls 를 읽지 못하므로 `pip install pyarrow xlrd` 가 추가로 필요합니다.

## 쓰는 법

### 화면에서

실행하면 창이 열립니다. **학습데이터 폴더**와 **시험데이터 폴더**를 지정하고 `검사 시작` 을 누르면 됩니다. 폴더를 칸 위로 끌어다 놓아도 되고, 경로를 붙여넣어도 됩니다.

검사가 끝나면 아래 **요약** 탭에 결과가 나오고, HTML 리포트가 자동으로 열립니다. 리포트는 **다운로드 폴더**에 저장됩니다.

```
중복성검사_리포트_20261023_143012.html
```

### 명령줄에서

```
python cli.py --train <학습폴더> --test <시험폴더> --out <리포트폴더>
```

임계값과 컬럼 설정도 옵션으로 줄 수 있습니다. `python cli.py --help` 참고.

## 검증

검사기가 맞게 판정하는지 확인하는 도구가 `tests/` 에 있습니다. 중복을 의도적으로 심은 데이터를 만들고, 몇 건이 잡혀야 하는지 기대값을 먼저 확정한 뒤 실제 결과와 대조합니다. **생성과 대조가 한 쌍**입니다.

```
python tests/make_format_samples.py <폴더>      확장자별 데이터 생성
python tests/verify_format_samples.py <폴더>    기대값과 대조
```

대량으로 보려면 `make_bulk_samples.py` (확장자당 1000단위) → `run_bulk_report.py` 를 쓰고, 그 밖에 `make_sample.py` → `test_engine.py`, `gui_smoke.py` 가 있습니다.

## 폴더 구성

```
app.py                GUI
cli.py                명령줄
dupcheck/             검사 엔진
  config.py           설정·확장자 정의
  discover.py         파일 분류
  engine.py           검사 실행
  filecheck.py        파일 단위 (SHA-256)
  tabular.py          정형 테이블 (행 단위)
  imagecheck.py       이미지 (픽셀 해시 + dHash)
  textcheck.py        텍스트 (MinHash + LSH)
  arraycheck.py       NumPy 배열 · PKL
  report.py           HTML 리포트
tests/                검증 도구
build_exe.bat         EXE 빌드
```

## 알려진 한계

- **영상·음성은 내용을 비교하지 않습니다.** 바이트까지 같은 파일만 잡힙니다. 재인코딩한 영상은 같은 원본이어도 탐지되지 않습니다.
- 근사 중복은 통계적 판정이라 소수의 오탐·미탐이 있을 수 있습니다. 최종 판단은 리포트에 표시된 위치의 원본을 직접 확인해 주세요.
- 읽지 못한 파일은 해당 검사에서 빠집니다. 전체 판정은 읽기 실패 건수를 반영하지 않으므로, 판정과 읽기 실패 수를 함께 보세요.
